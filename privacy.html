プライバシーポリシー

最終更新日：2026年10月18日

auto-news（以下「本ツール」）は、運営者が自身のYouTubeチャンネルへ動画を投稿するための個人用ツールです。本ツールにおける情報の取り扱いは以下のとおりです。

1. 利用するGoogleユーザーデータ

本ツールは、YouTube Data API を通じて、運営者本人のGoogleアカウントに対し「YouTubeへの動画のアップロード」（youtube.upload）の権限のみを使用します。動画とその説明文・サムネイルの投稿以外の目的には使用しません。

2. 情報の保存

認証のためのトークンは、運営者のPC内にのみ保存されます。外部のサーバーへの送信や保存は行いません。

3. 第三者への提供

取得した情報を第三者に販売・提供・共有することはありません。

4. 外部サービス

本ツールは YouTube API サービスを使用しています。本ツールの利用には YouTube 利用規約 が適用され、Googleによる情報の取り扱いについては Google プライバシーポリシー をご確認ください。

5. アクセス権の取り消し

本ツールに付与したアクセス権は、Googleアカウントのセキュリティ設定ページ からいつでも取り消すことができます。

6. お問い合わせ

本ポリシーに関するお問い合わせは、運営者のYouTubeチャンネルまでご連絡ください。
